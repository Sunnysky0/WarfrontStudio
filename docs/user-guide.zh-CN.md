# 战争前线动画工作室 — 使用指南

[English guide](./user-guide.md)

这是一款跑在浏览器里的**战线地图动画工作室**。你把国家、省份划给各方势力，用关键帧做领土易手（自动绘制的推进前线），或**手绘一条不受省界束缚的前线**，再配镜头、标记、旗帜和字幕，然后在浏览器里导出帧精确的 **MP4** 或 **WebM**。

本文面向**使用工作室的人**，不是开发文档。应用内的「战地指南」（工作区侧栏，或项目里的 Help）只是短清单；完整流程以本文为准。

## 1. 你需要什么

| 条件 | 说明 |
| --- | --- |
| 桌面浏览器 | 推荐 **Chrome 或 Edge**。MP4 导出走 WebCodecs（H.264）。Firefox 和较旧的 Safari 会退回到实时录制 WebM。 |
| Postgres | 必需。没有 `DATABASE_URL` 时工作区无法加载。 |
| 本地运行 | 需要 Node.js，外加 Docker Desktop **或** 随仓库附带的 Postgres 二进制。 |
| 屏幕 | 编辑器是桌面级密集布局（顶栏、侧栏、地图、属性、时间轴），请用较宽的窗口。 |

视频在**你的浏览器里**编码。没有服务端编码器，也没有云端渲染队列。导出结束前不要关标签页。

预览和导出共用同一套地图渲染器。画布上看到的内容（不含选区高亮等编辑叠加，也不含画布四周的舞台文字）就是成片内容。

## 2. 本地启动

在项目目录执行：

```bash
npm install
cp .env.example .env.local
npm run db:up
npm run db:push
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

- `npm run db:up` 优先用 **Docker Desktop**（`postgres:16`，绑定 `127.0.0.1:5432`）。Docker 没开时，会退回到 `.cache/pgsql-16` 里的附带二进制，数据在 `.data/pgdata`。
- 若系统 VPN 代理了回环地址，本地 Postgres 会连不上。请在 `.env.local` 里保留 `NO_PROXY=localhost,127.0.0.1`（`.env.example` 已写好）。
- 工作区第一次加载且项目表为空时，会自动写入一份 **「大亚洲战争」** 模板。这份种子**没有**删除保护，可以删掉。

不用时执行 `npm run db:down` 关掉数据库。

## 3. 十分钟做完第一个项目

最快的学法是打开模板，而不是从空白世界起步。

1. 首页打开 **Templates**（或 **New project**），在 **The Great Asian War** 下点 **Open a fresh copy**。
2. 等底图加载完（状态栏，或画布上的 “Loading basemap…”）。
3. 按 **空格**（或顶栏 **Preview**），看完 2022–2034：台海危机、政变、巴基斯坦介入、人民天朝、印度分裂、净化区、澳大利亚画中画。
4. 在**时间轴**上点各个片段。右侧 **Properties** 会切到对应事件。
5. 暂停。在时间轴 **Drawn frontline** 轨点开台湾登陆片段——那是一块沿岸滩头，不是整个屏东县。若要政治易手：把 **Unit** 改成 **Provinces**，涂选地区后 **Create event**。
6. 平移、滚轮缩放地图，再点工具栏准星（**用当前视图设镜头关键帧**）。
7. 打开 **Export video**，截一段短范围（例如 0–5 秒），720p、30 fps，下载 MP4。

准备自己做时：新建 **Blank project**，选边框年份，添加势力，涂上初始领土，再往时间轴加事件。

## 4. 工作区

首页是四栏工作区，顶栏 / 侧栏 / 状态栏尺寸与工作室一致。

| 侧栏 | 内容 |
| --- | --- |
| **Projects** | 已保存的项目。可按名称或描述搜索。点卡片进入工作室。悬停后可删除（卡片内确认，不是浏览器 `confirm`）。 |
| **Templates** | 从 **大亚洲战争**、**空白世界** 或 **导入 JSON** 开始。 |
| **Assets** | 工作室自带能力清单（底图层、历史年份、事件类型、导出格式）——不是你上传的文件。 |
| **Guide** | 六步短指南和快捷键表。 |

项目页的 **New**：

- **Blank project…** — 60 秒，墨卡托、当代国界、Neon Noir 主题，一条年份标记（`1914`）。可在 Templates 页填写名称。
- **The Great Asian War** — 120 秒功能样例（2022–2034，霓虹黑色，当代国界）。每种事件类型都有意用到。
- **Import JSON…** — 载入项目文档（见 [JSON 导入](#json-导入)）。

底部状态栏显示项目数量，以及能否连上 Postgres。

## 5. 工作室界面

由外到内：

```
顶栏            词标、重命名、保存状态、撤销/重做、Preview、Export
菜单栏          File / Edit / View / Help，以及回到工作区的面包屑
[ 图标栏 | 左栏? |  场景条 → 地图工具栏 → 地图画布 → 视图条  | 属性栏? ]
                 时间轴   （横跨地图+属性，不覆盖图标栏和左栏）
状态栏
```

各栏开合、选中的页签、时间轴缩放**只存在于编辑器**，不会写入项目，因此不会让预览和导出对不上。

### 顶栏

- 点击项目标题可重命名。时长以胶囊显示（`120s`）。
- 保存状态：**All changes saved** / **Unsaved changes** / **Saving…** / **Save failed — retry**。
- **Preview** 在画布上播放或暂停时间轴，不是另开窗口。
- 底图没加载完时 **Export video** 不可用。

### 左侧图标栏

| 页签 | 作用 |
| --- | --- |
| **Layers** | 15 个地图图层的显隐，顶部项目卡片会打开地图属性。 |
| **Nations** | 各方势力。数字是**当前播放头**下拥有的地区数。 |
| **Assets** | 旗帜预设、你的上传、标记种类、色板。 |
| **Guide** | 工作室战地指南和快捷键。 |

图标栏底部箭头返回工作区。**View → Left panel / Properties panel** 只隐藏栏目，不改文档。

### 场景条

项目文件里**没有**「场景」这种数据结构。「Scene 03 · 标题」是推出来的：

- 播放头之前（含）最近一条 **year** 事件决定章节号（`01`、`02`…）。
- 播放头处正在显示的 **subtitle** 作为标题；没有字幕时用年份文字。

下拉菜单可跳到各年份事件。**+** 在播放头插入一条年份。同一标题会出现在**舞台四周**的说明里（在画布外面，不会进成片）。

### 地图工具栏

- 工具：**选择地区**、**平移**、**放置标记**。
- **Unit**：**Countries** 或 **Provinces** — 点击命中哪一级。
- 准星：**用当前视图写入镜头关键帧**。
- 眼睛：仅编辑器里开关 **HUD 预览**（年份、交战旗帜、字幕）。导出仍会按事件绘制 HUD。
- 分辨率：项目的输出尺寸（画布和默认导出）。

### 地图画布

画布就是视频画面。四周暗角上的名称、宽×高×时长、场景标题、光标经纬度**不会**烧进导出文件。

### 视图条（地图下方）

当前工具提示；若你已平移/缩放过，会出现 **Free camera**；经纬度；缩放 − / +；以及把预览重新钉回时间轴镜头的复位。

### 属性栏（右）

三种模式：**Map** | **Event** | **Nation**。选中片段或势力时，会在同一次点击里切模式并打开面板。

只要地图上有选区，**Map selection** 会钉在模式切换**上方**，把地区交给某势力不必再翻页签。

### 时间轴

十轨，每种事件一条。见 [第 9 节](#9-时间场景与时间轴)。

### 状态栏

保存状态、边框年份、投影、底图加载、描述、输出尺寸，以及打开指南的 **Shortcuts**。

## 6. 地图与项目设置

在属性栏打开 **Map**，或点击 **Layers** 顶部的项目卡片。

左边图层是**显隐**，右边地图属性是**配置**。两边写的是同一套项目字段。

### 项目

标题与描述。标题也可在顶栏改。描述出现在工作区卡片和状态栏。

### 历史国界

| 年份 | 底图 |
| --- | --- |
| Present day | Natural Earth 国家级 |
| 2010、1994、1960、1945、1920、1914、1900 | 历史国家多边形 |
| 1935 | 实际用最接近的 **1930** 快照 |
| 1939 | 实际用最接近的 **1938** 快照 |

**省份始终是当代一级行政区**，即使国家轮廓是 1914 年的。这是数据限制，不是故障。

国家 id 随年份变化。当代中国是 `c:CHN`；1914 年地图上是历史名称（如 `cn:…`）。项目里若一边写 `c:CHN`、一边把 **border year** 设成 1914，中国不会上色——改年份，或改用按名称的键（`cn:` / `pn:`）。见 [第 19 节](#19-地区键进阶)。

改年份或细节等级会重新加载底图（状态栏转圈）。

### 投影

| 投影 | 常见用途 |
| --- | --- |
| Mercator | 默认；区域战役 |
| Equirectangular (Plate Carrée) | 简单世界图 |
| Robinson、Natural Earth、Equal Earth、Winkel Tripel、Miller、Mollweide | 世界图，两极变形较小 |
| Orthographic (Globe) | 地球仪 |
| Satellite (Tilted Globe) | 带倾角的地球 |
| Stereographic、Azimuthal Equal Area | 极地 / 区域球面 |
| Lambert Conic Conformal | 中纬度战场 |

球面类投影转动地球；圆柱类平移经度并居中纬度。正割圆锥会把标准纬线跟着镜头纬度重设。

### 地图细节（LOD）

| 等级 | 比例 | 何时用 |
| --- | --- | --- |
| Low | 1:110m | 快速草稿 |
| Medium | 1:50m | 默认 |
| High | 1:10m | 成片、要精细海岸线时 |

High 更重。草稿用 medium，1080p/4K 导出前若在意海岸再开 high。

### 主题（**视频**的外观）

主题只给画布/成片上色，不会改工作室那套墨绿界面。

- Neon Noir (Fire Rises) — 霓虹黑色
- Classic Atlas (Parchment) — 羊皮纸图集
- Cold War Blueprint — 冷战蓝图
- Minimal Light — 浅色极简
- Blood & Iron — 血与铁
- Night Lights — 夜灯

### 密度与风格

- **Label scale** — 势力 / 国家 / 城市字号。
- **City density** / **Sea label density** — 拥挤时留下多少地名。
- **Projection precision** — 自适应重采样。数值越低曲线越顺、绘制越慢。
- **Coastline glow** — 海岸发光开关。

### 输出分辨率

预设：720p、1080p、1440p、4K、正方形 1080、竖屏 1080×1920。宽高也可手填（偶数）。这是**文档**尺寸：预览画布和默认导出大小。导出对话框里可以单次覆盖。

镜头的 scale 不跟像素宽度绑死，同一项目可以在 720p 和 4K 导出，不必重做关键帧。

### 默认镜头

第一条镜头关键帧之前使用的经度、纬度、scale。**Use current view** 把当前预览拷进去。在 `0:00` 设关键帧也是写这个默认值（不会插入镜头片段）。

### 图层（左栏）

十五个开关，分组如下：

| 分组 | 图层 |
| --- | --- |
| Nation layers | 势力轮廓、势力名、中立国名 |
| Base map | 陆地填充、海岸、国界、省界、湖、河、铁路 |
| Labels & cities | 城市、城市名、海名 |
| Atmosphere | 经纬网、暗角氛围 |

徽章 `N/15 on` 是当前可见层数。搜索可过滤列表。开关图层**会**写入项目，**会**影响导出。

Layers 底部的 **Auto-draw frontlines** 把当前地图选区交给选中的势力（或第一个势力），生成 3 秒自动前线。

## 7. 势力与旗帜

**势力（Nation）** = 名称 + 颜色 + 可选旗帜 + 在 `0:00` 拥有的地区键。之后的 **Territory** 和 **Disintegration** 会改写归属。地图不能手绘「占领多边形」——你只分配地区。

### 新建势力

1. 可先涂选国家/省份（会成为初始领土）。
2. 打开 **Nations**，点 **+**，或空状态下的 **New nation**。
3. 属性栏进入 **Nation**：名称、颜色（取色器或色板）、旗帜、可选备注。
4. **Initial territory** 列出地区芯片。可从地图选区追加、替换、按名搜索，或 **Show on map**。

删除势力会二次确认。时间轴上仍引用该势力的事件**不会**被删掉；只是暂时没有颜色，直到你改指向。

Nations 列表每行的数字是该方**此刻**（播放头）拥有的地区数，不是初始列表的长度。

### 旗帜

在势力属性（或势力更名 / 交战旗帜事件）里：

| 类型 | 做法 |
| --- | --- |
| 预设 | 当代国家（ISO）、历史（俄罗斯帝国、德意志帝国、清朝…）、大亚洲战争虚构（天朝、PDTO…） |
| 任意 ISO 码 | 两字母代码，加载 `/flags/CN.svg` 等 |
| 图片 URL / data URL | 你的上传，或外链 |
| 自定义生成器 | 横条 / 竖条 / 纯色，逗号分隔颜色，可选徽记（星、日、新月、十字、菱形、八角星、锤、三叉戟、圆），可调大小和 x/y |

先选中一个势力，再在 **Assets** 里点预设或色块即可套用。

标签覆盖：用准星在地图上点经纬度，可改缩放、颜色，或隐藏标签。

## 8. 点选与涂抹领土

把 **Unit** 设成 **Countries** 或 **Provinces**。使用 **Select** 工具（箭头）。

| 操作 | 结果 |
| --- | --- |
| 单击地区 | 只选中该地区 |
| Shift+单击 | 加入选区 |
| Ctrl/Cmd+单击 | 切换该地区 |
| Shift+拖动 | 涂抹：指针扫过的地区都会加入 |
| 点空白海洋 | 清空选区（按住 Ctrl/Cmd 时除外） |
| Esc | 清空选区（也会取消经纬度拾取） |
| 不按 Shift 拖动 | 平移（选择工具下同样如此）。滚轮相对光标缩放 |

悬停显示地区名。视图条和右下角舞台文字显示经纬度。

选中地区在画布上高亮（编辑叠加——**不会**导出）。

### 把选区交给势力

选区非空时，属性栏 **Map selection**：

1. **Transfer at playhead** — 选势力、动画模式、时长（秒）→ **Create event**。在播放头插入一条领土片段，然后清空选区。
2. **Add to “某势力” initial territory** — 仅当已选中某势力。改的是 `t = 0` 的归属，不是后来的征服。

也可以在已有领土事件、解体后继方、或势力初始列表上用 **Add selection** 追加/替换。

## 9. 时间、场景与时间轴

全片只有**一个时钟**：视频时间 `t`，从 `0` 到项目 **duration**（秒）。播放、刮擦条、导出都用它。年份是 HUD 文字，**不**驱动地理。

事件区间是左闭右开 `[start, end)`。

- HUD 类（字幕、地图文字、标记、交战旗帜、画中画）在 `start ≤ t < end` 时可见。
- 领土归属在 **`end` 提交**；**instant**（或 `end ≤ start`）则在 `start` 提交。前线推进过程中你看到的是遮罩，不是最终主人。

### 走带

- 播放/暂停：空格、顶栏 **Preview**、或时间轴播放键。
- 跳到开头：Home，或后退按钮。
- 跳到结尾：前进按钮（没有 End 键）。
- 微调：← / → 步进 0.5 秒，Shift+方向键 5 秒。
- 刮擦：在时间尺上拖动。

播到时长尽头会停。时间显示旁边的数字框**就是**项目总长；要在旧终点之后加片段，先把这个数加大。

### 片段

- 单击片段以选中并打开事件属性。
- 拖中段移动；拖两端裁切。拖动时最短 0.1 秒。
- **磁铁**吸附到 **¼ 秒**。需要更细可关掉。
- − / 滑条 / + 缩放时间轴（每秒像素）。
- **Duplicate**（Ctrl/Cmd+D）在原片段**紧后面**放一条同样长度的副本。
- **Delete**（Delete 或 Backspace）删除选中事件。

Tracks 标题上的 **+** 在**播放头**添加事件。各类型的默认时长、文案见 [第 10 节](#10-事件类型)。

### 轨道

自上而下：

年份 → 镜头 → 领土/前线 → 解体 → 势力更名 → 标记 → 地图文字 → 字幕 → 交战旗帜 → 画中画

同一类型重叠的片段会加出额外行。

**锁定**（轨道标题上的锁）：仍能选中，不能拖。**折叠**（眼睛）：只在编辑器里藏起该轨。这两项都不保存，也**都不会改成片**。

## 10. 事件类型

每条片段都有可选的时间轴 **label**，以及以秒计的 **start** / **end**。

| 类型 | 作用 | 添加时的默认长度 |
| --- | --- | --- |
| **Year counter** | 左上角 HUD 年份（或任意短字）。`start ≤ t` 的最晚一条生效。 | 1 秒（不必铺满整章） |
| **Camera** | 在 `[start, end]` 内从上一镜头（或默认镜头）插到本目标。 | 3 秒 |
| **Territory / Frontline** | 把列出的地区动画交给某势力；在 `end` 提交归属。 | 3 秒 |
| **Disintegration** | 把一方拆成若干后继。 | 3 秒 |
| **Nation transition** | 名称 / 颜色 / 旗帜 / 标签交叉淡化。 | 2 秒 |
| **Marker** | 战斗、核、舰等，落在经纬度；可加额外点做集群。 | 4 秒 |
| **Map text** | 地图上的大写文字（可拾取锚点）。 | 4 秒 |
| **Subtitle** | 标题卡：左下、顶中或正中；发光或带框。 | 4 秒 |
| **Belligerent flags** | HUD 里左右两排旗帜。 | 10 秒 |
| **Inset map** | 画面一角的第二台镜头。 | 10 秒 |

## 11. 镜头

镜头是**经度、纬度、scale**（地球仪上还可选 roll）。scale 是按 1920 像素宽归一化的缩放，不必把 4K 写进这个数字。

### 实时视图 vs 时间轴镜头

平移（拖）和缩放（滚轮，或视图条 − / +）写入**预览覆盖**。会出现 **Free camera**。时间轴此时还没改。

- **Follow timeline camera**（工具栏撤回图标、芯片本身、View 菜单、或视图条复位）丢掉覆盖。
- **Set keyframe from view**（准星）：
  - 在 **0:00** → 写入**默认镜头**。
  - 在 0:00 之后 → 插入一条 **Camera** 事件，结束于播放头（起点往前 3 秒，不少于 0）。

在镜头片段上，**Use current view as target** 把实时镜头拷进该关键帧。缓动：ease in-out（默认）、ease out、ease in、linear。

scale 在对数空间插值（缩放观感均匀）。经度走日界线的短弧。

**拾取**模式（经纬度旁的准星）：工具栏会闪「Click the map to pick a point — Esc cancels」，点完回到原来的工具。

## 12. 前线（领土转移）

领土事件包含：**地区列表**、**接收方**、可选 **进攻方 / from**（决定扫过方向）、**模式**、可选 **原点** 或 **方向**、**粗糙度**（0–1，让前线不是正圆）、**缓动**、**绘制发光前线**、以及 **国家转移时清除省级覆盖**（默认开）。

### 模式（属性栏）

| 模式 | 观感 |
| --- | --- |
| **Auto frontline (from attacker)** | 默认。从进攻方腹地扫入（没有 from 时用接收方）。过小的地区改为淡入。 |
| **Radial sweep from origin** | 从你点的经纬度（或地区中心）向外扩。 |
| **Linear front (direction)** | 直线推进。方向：角度，**0 = 东，90 = 北，−90 = 南**。 |
| **Fade** | 交叉淡化，没有行军线。 |
| **Instant** | 在 `start` 立刻改归属，没有进行中的遮罩。 |

粗糙度让边缘不规则。安静的淡入可关掉 **Draw glowing frontline**。

### 国家 vs 省份

可以先把整个国家划给某方，再转移其中若干省。转移**整个国家**时，默认的 **Country transfer clears province overrides** 会清掉该国之下的省级例外，让新主人拿到完整 ADM0。

前线不出现时检查：

- 地区键必须在**当前边框年份**的底图上存在（见 [第 19 节](#19-地区键进阶)）。
- **接收方**势力还在。
- 除非是 instant，否则 `end` 必须大于 `start`。
- 你看的时间要落在 `[start, end)` 内——过了 `end` 地块只是该势力的填色。

### 手绘前线

战线需要**切开省界**时，添加 **Drawn frontline** 片段（时间轴 **+**，或工具栏样条工具）。它**不会**改地区归属键，只根据你画的折线涂占领色。

1. 在播放头添加片段（默认 8 秒）。占领方 = 当前选中的势力。
2. 在地图上点击放置顶点。双击或 **Enter** 完成一个关键帧。点靠近第一个顶点可闭合（登陆圈 / 包围圈）。
3. 拖动播放头。工具栏样条按钮或属性里的 **Set keyframe at playhead** 会把插值后的线存成新关键帧。
4. 拖手柄编辑。点线段插入顶点。在关键帧上点空白处设置 **captured side**（哪一侧被占领）。
5. 属性：占领方 / 防守方、填充裁到双方领土（默认）或冻结的地区列表、填充、发光、闭合、**片段结束后保持最后一帧形状**。

有防守方时填充裁到双方土地；否则裁到陆地并在线周围留垫，避免一次登陆涂满整个大陆。

新建片段默认保持结束形状。Great Asian War 模板里的战役关掉保持，并在结束时用 instant 领土事件提交政治归属。

坐标仍是 **经度, 纬度**。不要用一条线穿过日界线，分成两段。

## 13. 势力更名与解体

### 势力更名（Nation transition）

选一个势力，可选**新名称**、**新颜色**、**新旗帜**、新标签位置。颜色和名称在起止之间**交叉淡化**（例如俄罗斯帝国 → 苏俄）。旗帜大约在中点切换。

名称留空则保持原名。只有要变色时才勾 **Change colour**。

### 解体（Disintegration）

1. 添加 **Disintegration** 事件。
2. **Nation that breaks apart** = 被拆的一方。
3. 模式：**Shatter (staggered)**（后继错开出现）、**Fade together**、或 **Instant**。
4. **Dissolve everything else the nation owned** — 父势力剩下的土地清空。可选把剩余交给另一方。
5. **Add successor state** — 用当前地图选区作为该后继的地区。可重复。每个后继有自己的势力选择和地区列表。

请先建好后继**势力**（名、色、旗），再让各 part 指向它们。

## 14. 叙事层：年份、字幕、地图文字、标记、旗帜、画中画

### 年份

从该时刻起在 HUD 显示这串文字，直到下一条年份事件。可以是 `2022`、`1914 冬`，或任意标签。场景条上的章节号来自年份事件的**顺序**，不是文字内容。

### 字幕

正文；**plain (glow)** 或 **boxed**；位置 **左下**、**顶中** 或 **正中**。正在显示的字幕同时给场景条当标题。

### 地图文字

可多行，在地图经纬度上以大写绘制。可调大小、颜色。用 **Pick** 在地图上点锚点。（这是画面内的字，和画布四周的 DOM 说明不是一回事。）

### 标记

| 图标 | 典型用途 |
| --- | --- |
| Nuclear strike | 核打击 |
| Explosion / strike | 通用爆炸 |
| Fire / bombardment | 火攻 / 轰炸 |
| Battle (crossed swords) | 陆战 |
| Massacre / disaster | 骷髅 |
| Capital / key point | 星标 |
| Naval landing | 登陆舰 |
| Air raid | 空袭 |
| Armored offensive | 坦克 |
| Flag / occupation | 占领旗 |
| Chemical weapons | 毒气 |
| Ballistic missile | 导弹 |
| Siege | 围城 |
| Revolt / uprising | 暴动 |

放置方式：

- **Place marker** 工具：在工具栏选种类，点地图。片段从播放头起、长 4 秒、落在该经纬度。
- **Assets → Markers**：在**视图中心**落下该种类。
- 时间轴 **+ → Marker**。

属性：大小、颜色、脉冲，以及 **extra positions**（再点若干点做齐射）。

### 交战旗帜

HUD 一排，通常在左上：**左**方对 **右**方。每侧有标签、可选阵营徽、以及势力勾选。一侧**第一个勾上的**势力用大旗。

### 画中画

画面一角的第二台镜头（默认右下）。标题、经纬度/scale（或 **Use current view**），宽高是画面比例（默认约 0.3 × 0.36）。画中画与主图同一套图层和主题。

## 16. 保存、撤销与 JSON 导入

### 自动保存

编辑会把项目标成 **dirty**。空闲 **4 秒**后工作室把完整文档 PUT 到服务器。**Ctrl/Cmd+S**（File → Save，或云朵图标）立即保存。

顶栏云朵就是保存按钮。若出现 **Save failed — retry**，多半是 Postgres 挂了或网络断了；修好后再存一次。

标签页在 dirty 时关掉，可能丢掉最后几秒的修改。离开前等到 **All changes saved**。

### 撤销

最多 **80** 步文档历史。**Ctrl/Cmd+Z** 撤销，**Ctrl/Cmd+Shift+Z** 或 **Ctrl/Cmd+Y** 重做。拖片段、平移地图这类手势不会把每帧都推进历史：松手时才记一步。

界面状态（开着哪些栏、页签、轨道锁/折、时间轴缩放、自由镜头）**不在**撤销栈里，也**不会**保存。

### JSON 导入

在工作区导入 `.json` **项目文档**：含 `version`、`name`、`description`、`duration`、`map`、`nations`、`events` 的对象。

- `version` 必须是 **1**。目前没有其它版本的迁移器。
- 文件里的坐标是度制的 `[经度, 纬度]`，不是 `[纬度, 经度]`。
- 工作室界面**目前没有**「下载 JSON」。项目活在 Postgres 里并自动保存。要归档文件，请自行拷出已有项目的 `data`，或保留当初导入的那份。

空库会先种入大亚洲战争模板；再导入 JSON 会**另建一行**。

## 17. 导出

**Export video**（顶栏或 File 菜单）打开对话框。

| 项 | 选项 |
| --- | --- |
| Format | **MP4 (H.264)** 或 **WebM (VP9)** |
| Resolution | 项目尺寸，或 720p / 1080p / 1440p / 4K / 方 / 竖 |
| Frame rate | 24 / 30 / 60 |
| Bitrate | 1–80 Mbps（默认 12） |
| Start / End | 秒；默认整段时长 |

对话框会显示帧数（`秒 × 帧率`）。**Render & download** 开始编码。有 WebCodecs 时按帧显示进度。

- **Chrome / Edge**（以及带 WebCodecs 的较新 Safari）：离线、帧精确。若浏览器会节流后台标签，请把该页留在前台。
- 没有 WebCodecs 或编码失败：用 MediaRecorder **实时录 WebM**（边播边录）。更慢，也不保证逐帧对齐。
- **Esc** 在空闲时可关对话框；渲染进行中不会关，以免误触中断。
- **PNG snapshot** 把当前播放头导出为一张静帧（含 HUD，不含编辑叠加），分辨率用对话框里选的。

导出与预览**同一套渲染**：图层、主题、归属、前线、HUD 事件。**不含**选区高亮、悬停、拾取准星，也不含画布四周的 DOM 说明。

编辑器里关掉 **HUD preview** 只影响你工作时的画面；导出仍会画年份 / 旗帜 / 字幕。

导出期间不要关标签。120 秒 1080p30 是数千帧；4K 和 60 fps 更吃 CPU，文件也更大。

## 19. 地区键（进阶）

每个国家和省份有稳定 id。平时不用手打——点地图，或在地区列表里按名称搜索即可。填色出不来、或你在导入 JSON / 改模板时，才需要看这些键。

| 键 | 含义 | 例子 |
| --- | --- | --- |
| `c:CHN` | 当代国家（ISO3 / ADM0_A3） | **present** 国界上的中国 |
| `c:Austro-Hungarian_Empire` | 历史国家；空格变成下划线 | 1914 快照 |
| `p:USA-NY` | 省 / 一级行政区代码 | 纽约 |
| `pn:JPN:Tokyo` | 国家代码 + 省名 | 不区分重音；会去掉末尾的 prefecture |
| `cn:Russian Empire` | 按显示名找国家 | 在已加载的国家要素里查找 |

`pn:` 和 `cn:` 是给人写的别名。底图加载后会解析成 `p:` / `c:`。解析失败的键会原样留下，**不会填色**。

在地区列表里搜（至少两个字符）会帮你加上规范 id。

**当代**快照用 ISO3（`c:CHN`）。**历史**快照用下划线名称。键必须和 **Historical borders** 一致。

## 20. 技巧与易错点

**从模板起步。** 大亚洲战争是每种事件的工作样例，不只是故事。

**先涂再交。** 不用手绘占领范围。选地区 → Create event / 加入初始领土。

**默认镜头 vs 镜头片段。** `0:00` 的取景是默认镜头。之后的运动是 Camera 事件，从上一个目标插过来。

**Free camera 只是预览。** 地图不跟时间轴走时，点 **Free camera** 或复位。

**立刻占领 vs 推进。** 时长 0 或 Instant 会马上提交。3 秒自动前线需要你看的镜头落在 `[start, end)` 里。

**清除省级覆盖。** 转移整个国家时保持开启，避免旧主人颜色剩下一堆「蜂窝」省。

**年份只是标签。** 改 year 事件不会变成 1914 年国界。国界请改 **Historical borders**。

**HUD 开关是编辑用的。** 导出仍会合成年份、旗帜和字幕。

**High LOD + 4K + 60 fps** 是最重路径。草稿用 medium / 1080p / 30 fps。

**删势力不会删事件。** 那些片段要自己改指向或删掉。

**轨道锁/折是本地的。** 换一台机器或刷新后，轨道会全部展开、解锁。成片不变。

**坐标顺序是经度、纬度。** 属性栏如此标注。JSON 必须一致。

**字体。** 地图标签按主题使用 Josefin Sans / Cinzel / Oswald / Share Tech Mono。Google 字体加载失败时仍会导出（走回退字体），但和加载成功的机器不完全一样。

**无多人、无云分享、无登录。** 这是本地工作室加 Postgres。搬家请拷数据库，或拷一份 JSON 文档。

**不要手改 `public/basemap/` 下的文件。** 那是编译好的 TopoJSON。年份不对或填不上色，几乎都是地区键或边框年份不匹配，不是缺文件。
